## 功能范围

- macOS 菜单、文件对话框和 sheet：保留逻辑 app、实际 surface owner 和父子关系；新对话框可发现、截图、操作；只阻止确实受其影响的目标。关联证据不成立时明确拒绝，不用标题或几何独立猜归属。
- 有界区域/子树发现及按需长文本读取，继续使用已有窗口和观察引用，不返回整棵 AX 树。菜单发现复用相同 app 协议。
- Windows 原生查询使用匹配文本而非显示摘要，搜索预算不足必须报告 partial；平台不支持的新能力明确声明。
- Skills 和 API 与实现一起收口：普通 Agent 只用 `exec(app, source)`，复杂状态和 owner 路由保留在 DTW 内部。
- Skill 主文档说明通用协议、能力和引用生命周期；按需参考说明文件选择器、表单、动态控件及大树发现等可复用交互。具体应用或验收任务的操作步骤不进入 Skill。

锁屏、远程 MCP、完整 DOM/tab provider、Windows 后台输入和 Linux 支持承诺独立后置。本批不恢复旧 CUA SDK/worker；固定来源的能力闭包继续移植并薄适配。

## 实机任务

沿用历史 WPS、Obsidian、Chrome 案例的业务目标，增加完整结果闭环。每次使用唯一临时路径、数据和标记，不操作个人文档/笔记/浏览器 profile。

| 应用 | 完整任务 | 独立结果证据 |
| --- | --- | --- |
| WPS Office | 从自有起始文档新建文档，输入中文/英文、多段正文，完成一次修改；经原生另存为选择新目录与名称，保存、关闭、重新打开并检查 | DOCX ZIP 中的文档文本/段落；原起始文件 hash 不变；Agent 的重新打开 GUI 读回 |
| Obsidian | 从隔离欢迎页创建 vault，经原生目录选择器指定目录；创建文件夹及两篇笔记、内部链接，搜索并重新打开目标笔记 | vault 的 `.obsidian`、两份 Markdown 内容与链接；Agent 的搜索/重新打开读回 |
| Chrome | 复杂业务页面中筛选跨页记录，编辑字段、复选框、多行中文与 emoji，保存一次；重新打开核对，执行原生文件选择并验证所选自有文件 | 独立服务端保存日志、相邻记录未变、提交文件名与内容；不以 AXPress 成功代替业务成功 |

业务数据可由监督脚本准备和读回；执行 Agent 不得用 shell、DOM/CDP、HTTP 或直接文件编辑完成任务。启动和清理仅作用于监督脚本创建的资源。原操作结果未知时保留回执，不重放。

## 度量与验收

- **上手难度**：仅普通 MCP + 随包 Skill；记录元数据发现、脚本语法/API 误用、人工提示次数，以及 Agent 对难点的具体反馈。监督者提供业务目标和自有资源，不提供临时定制操作脚本。
- **效率**：每个任务保留总耗时、MCP/exec/原子方法调用数、输出 JSON/图像字节、失败调用、只读刷新和重做步骤。模型/网络故障单列，不能从失败分母中静默剔除。
- **覆盖度**：逐项核对任务子目标与独立结果；报告完整完成、部分完成、阻塞。原生、直接脚本、模型运行分别标记，不相互替代。
- **成功率**：同一冻结候选上 Claude、agy 分别运行；按应用报告完整任务成功数/尝试数，并保留首次失败和调优前样本。修改实现或 Skill 后使用新案例，不对未知写入恢复重放。
- 既有 Chrome 工作台任务保留原有成本门槛；WPS/Obsidian 新组合先明确业务完成标准，再用实测建立成本基线，不套用小 fixture 的八次 exec 限额。
- 外部 Agent 任务使用 900 秒监督预算；不额外截断固定模型轮数。达到监督预算的任务保留部分结果并计为未完成。这是验收运行的资源边界，不是 DTW 脚本或产品能力上限。

## 集中验证循环

1. 合并本批能力、协议、说明和必要回归，完成一次构建与合同检查。
2. 固定并记录源树、二进制、Skill hash；先做自有真实任务的直接 MCP 路线，再做全新外部 Agent 会话。
3. 按首次失败归因（能力、状态、接口、Skill、模型或环境）集中修复，再冻结新候选，只重测受影响任务与最终三应用闭环。
4. 形成任务指标表和残余缺口清单后，交接相同源版本的 Windows 验收。macOS 结果不外推 Windows；Linux 保持实验实现。

此文是实施与验收约定，不是通过记录。实际结果另附候选身份、原始日志和独立读回证据。
