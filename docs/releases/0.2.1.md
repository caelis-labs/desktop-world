# Desktop World 0.2.1

The [release assets](https://github.com/caelis-labs/desktop-world/releases/tag/v0.2.1)
and RELEASE.json identify the exact platform sources, hashes and acceptance scope.

## Changes

Windows uses targeted client-area mouse messages for supported HWND controls:
left single/double clicks and native-control wheel input. Chromium content supports
single left clicks through this route. The physical cursor stays fixed while the
session marker presents accepted posts. Other gestures, unknown receivers,
non-client input and keyboard operations automatically raise the exact target and
use the existing foreground route. Agents use ordinary methods without a routing
parameter. Applications can activate themselves while processing messages.

The adaptation stays inside the Windows backend, with Windows-conditional native
client wiring. It retains exact ownership, retained geometry/expiry, DPI-aware and
unaware coordinate conversion, a shared transaction lease, paired release and
cancellation cleanup. Possibly dispatched operations never switch routes or replay.
Synthetic pen/touch injection, foreign-thread suspension and foreign style changes
are not imported. See the [port record](../windows-cursor-port.md).

The packages also include main's changes to keep an automatically raised target
in front, remove internal identity badges from cursor feedback, and fit macOS
captures across mixed-scale displays. README installation prompts now select the
latest stable release through the permanent Releases link.

## Installation and limits

Use [installation](../../install.md) and keep the extracted package intact. Finish
active work before changing package paths and reconnect the Agent after upgrading.
Unknown input effects remain inspectable and are never automatically replayed.

This release does not provide an independent OS mouse or background keyboard per
Agent. Secure/elevated desktops, locked sessions, drag, app launch/quit, browser
DOM/profile APIs and remote transport remain outside the supported surface.
Normal-user Windows evidence does not certify every app, OS or display layout.
