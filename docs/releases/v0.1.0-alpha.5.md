Desktop World v0.1.0-alpha.5 adds an opt-in macOS cooperative input mode to reduce total occupation of the user's desktop. The host selects `dtw serve --input-mode cooperative`, `local.Options.InputMode`, or `host.Options.InputMode`. Reads, window capture and supported semantic actions keep their background paths; a known, short input plan borrows the foreground and restores the previous window and input focus before returning.

Supports scoped move, left/double/middle/right click, drag, horizontal/vertical wheel, Unicode and multiline text, modifier shortcuts, and same-plan binding of known menus/dialog controls. A one-second input budget stops subsequent input; native handoff/cleanup can exceed that budget. Text bursts are limited to 256 UTF-16 units and drags to 500 ms. Receipts report channel, foreground duration and restoration status. Cancellation releases owned synthetic keys/buttons; a user's switch to another application wins. Failed cleanup fences the seat; uncertain input is never automatically replayed. `no_shared_input` and existing grants remain strict ceilings.

Validation: independently executed native operations through dtw in AppKit, system WebKit, Google Chrome and a standard Electron BrowserWindow application; TextEdit saved an owned document with exact disk-byte verification. Includes menus, dialog text/confirmation, occluded-window captures, user resumption, cancellation, budget expiry and original-receipt reconciliation. See `poc/background-input/FULL_ACCEPTANCE.md` and `docs/evidence/cooperative-20261004/`. VS Code's isolated-profile startup did not expose the owned document and is explicitly unaccepted. Contract race/vet, Windows cross-build/vet, protocol and JavaScript checks plus three-platform CI are required for this release.

This is shared physical input on the same desktop. It uses dynamically probed private SkyLight / exact-window key-focus SPI; it does not introduce independent devices, a VM or another login session. macOS 27.0.1 arm64 is the real-machine validation environment. Minimum macOS, amd64, IME, arbitrary provider and same-app human-interruption compatibility remain unverified. Missing symbols/permissions refuse input. Original PID-routing probes remain experimental and do not silently fall back.

Distribution: macOS arm64 `bin/dtw`, source archive and SHA256SUMS, ad-hoc signed and not notarized. The archive includes applicable third-party MIT notices; Desktop World's own NOTICE grants no open-source license. Windows functionality/CI remain implementation evidence only, with no Windows usability promise. All Windows real-machine adaptation and caelis-bot M0 version update/integrated acceptance remain deferred.
