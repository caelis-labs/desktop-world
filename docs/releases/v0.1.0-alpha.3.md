Desktop World v0.1.0-alpha.3 completes the next two feature batches: explicit semantic selection/checking/scrolling and on-demand independent window capture.

- `dtw` is now the helper CLI name. Hosts must update executable paths; Go SDK and helper should come from the same release.
- `no_shared_input` provides a host ceiling that rejects focus/shared keyboard/pointer plans before effects. Explicit `set_expanded`, `set_selected`, `set_checked` and `scroll_into_view` use provider semantics, verify state, preserve no-op/unknown results and original receipts.
- macOS `capture_windows` discovers native capture Refs within an observed application. `window_content` uses ScreenCaptureKit without activating the target and returns target-local coordinates. It does not join AX windows by title/bounds or grant desktop click mappings. Images and richer fields remain opt-in and budgeted.
- Native attribute field selection, bounded AX/UIA continuation and managed host control/receipt recovery are included. The JavaScript adapter supports small scoped discovery and per-action schema disclosure.

Validation: independent macOS arm64 AppKit/WebKit feature scenarios F1/F2/F3/F6/F7/F8/F9, app-owned event logs, actual foreground Unicode input and window PNG pixel checks; race/vet/protocol/JavaScript tests and Windows cross-build checks. F9 covers covered content updates, moving/resizing, separate popup/sheet pixels, hidden/minimized refusal and restoration, recreated-window Ref invalidation, capture enablement and turn expiry. Detailed evidence and cost definitions are included under `docs/evidence/`.

This is an early macOS alpha, not a dual-platform availability release. Windows functionality is implemented but all real-machine acceptance/adaptation is deferred; **Windows usability and fresh-frame correctness are not promised**. macOS lock/disconnect/cross-display, mixed scaling, minimum-version and broader provider compatibility remain unverified on real hardware. P3 human-priority cooperative input and P4 long-session/event work follow separately. caelis-bot M0 version update and integrated acceptance remain deferred.

Distribution: macOS arm64 `bin/dtw`, source archive and `SHA256SUMS`. The macOS artifact is **ad-hoc signed and not notarized**; no open-source license is granted (see NOTICE). Verify checksums and `dtw version`/`doctor` before configuring a trusted host.
