# Desktop World 0.2.0

Published on 2026-11-01. The [release assets](https://github.com/caelis-labs/desktop-world/releases/tag/v0.2.0)
and their RELEASE.json identify the exact platform sources, package hashes and
acceptance scope. This page describes that release, not later main changes.

## What ships

The rewrite uses standard local stdio MCP and a canonical Agent Skill, without a
custom Host. `exec` takes a stable platform app ID and JavaScript source; the
Harness owns approval policy. The old CUA SDK/worker and 0.1.x entry points are not
compatibility paths.

The package provides window discovery, bounded semantic discovery, window
screenshots, semantic and image-coordinate actions, focus, Unicode text, keyboard
shortcuts, scrolling and value updates. One app ID aggregates running instances;
window references retain their exact owners. App contexts survive switching.
Compact results and inspectable receipts preserve uncertain effects without replay.

macOS includes conditional background input and Agent cursor feedback. Its original
foreground-borrowing behavior belongs to this version; later changes to leave the
target in front are not retroactively part of 0.2.0. Windows uses foreground input
and UIA with independent session cursor feedback, not background keyboard support.

## Artifacts and evidence

macOS arm64 (minimum deployment target 14.2) is Developer ID signed and notarized.
Windows x64 uses static CRT. ZIPs contain the executable, Skill, MCP examples,
plugin metadata, checksums and dependency notices. Running DTW requires no Rust,
Xcode, Node or CUA SDK installation.

The macOS package source is `df76b14d839044fa800a723bd1f3e557a96a4166`;
the Windows source is `da61485cd41cb0aee880139d94ab86c1e5bb5970`.
The release tag points to `48d07140b3af924ec73477832da3464b5532a9cb`.
The accepted archives were promoted without rebuilding. RELEASE.json records
Terra Chrome/Obsidian/WPS and DeepSeek Chrome installed macOS tasks, plus Windows
native and DeepSeek task acceptance. It explicitly separates earlier evidence,
not-rerun tasks and the original build-workflow failure from later local checks.

## Limits and installation

Use [installation](../../install.md) and keep the extracted package intact.
Finish active work before changing paths and reconnect the Agent after an upgrade;
uncertain actions are never replayed automatically.

Desktop permissions remain required. Locked-session operation, drag, app
launch/quit, browser DOM/profile APIs and remote transport are not provided.
Linux X11 remains experimental. The Windows evidence is limited to its recorded
Windows 11 ordinary-user environment; macOS deployment minimum and signing do not
prove fresh-machine permission flow, every older OS or every display layout.
