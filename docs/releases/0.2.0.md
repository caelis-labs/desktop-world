# 0.2.0 rewrite — release notes draft

This is a candidate draft, not a published release. The [candidate record](../rewrite-candidate-acceptance.md) owns artifact and platform acceptance. Windows independent desktop acceptance and macOS distribution trust must be resolved before a matching support claim or publication.

## What changes

DTW now ships its rewrite alone. Standard local stdio MCP and the canonical Skill connect ordinary Agents without a custom Host. `exec` requires only a stable platform app ID and JavaScript source; the Agent/Harness owns approval policy. Existing 0.1.3-era CUA SDK/worker packages and APIs are not compatibility entry points for this release.

The ten script methods cover app windows, bounded semantic discovery, precise window screenshots, semantic and image-coordinate actions, focus, Unicode text, keyboard shortcuts, scrolling and semantic value updates. An app ID aggregates its running instances. Each window reference targets its actual owner; one instance exiting or restarting does not discard an unaffected sibling's state/references. Multiple app contexts survive switching within a session, and physical input is coordinated across sessions.

Filtered discovery and pagination keep complex accessibility trees out of model responses. Scripts return compact summaries and separate screenshots; execution receipts preserve uncertain effects and support inspection without replay. See [the Skill](../../skills/desktop-world/SKILL.md) and [API contract](../app-script-v1.md).

## Runtime and packaging

Candidate targets are macOS arm64 (deployment minimum 14.2) and Windows x64. A complete extracted ZIP contains one executable, Skill, standard MCP examples, optional Claude plugin metadata, build/source identity, checksums and dependency notices. DTW itself requires no Rust, Xcode, CUA SDK or Node installation at runtime. Windows uses static CRT; its actual native imports are recorded in BUILD. macOS signature and notarization are distinct records, and the minimum deployment target is not proof of testing on every older OS.

Use the [installation guide](../install.md). Finish active operations before replacing an installation; extract a new directory, update the Agent's path and reconnect. Existing uncertain actions are not replayed during upgrade. Remove a stopped installation through ordinary Agent deregistration and removal of its directory.

## Boundaries

macOS and Windows need their platform's desktop access/permission conditions. Coordinate input uses the shared foreground keyboard and pointer; independent background input, a stationary user pointer, locked-session operation, drag and browser DOM/profile APIs are not provided. No app launch/quit API or remote transport is included. Linux X11 implementation remains experimental with no desktop support promise or formal package. Other CPU architectures and clean-machine/oldest-OS coverage require separate evidence.

The [core report](../release-core-acceptance.md) separates native fixture controls from realistic owned Chrome/TextEdit workflows through Claude and agy. The final installed artifact report must establish the same boundaries on the shipped bytes; compilation alone does not establish Windows desktop support.
