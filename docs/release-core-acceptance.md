# 首版核心两批实施与易用性验收

本轮按[发布计划](first-rewrite-release-plan.md)推进第一、二批施工。第三批候选制作、第四批安装产物验收有独立准入门槛；开发二进制和本地插件 stage 不冒充发行候选。实施基线为 `ec7bd98`（#65 计划，上一产品基线为 #64）。核心开发字节的 macOS 原生及外部模型验收已经收口；后续候选使用独立来源和验收记录。

**外部 Agent 六轮验收全部通过。** 同一冻结二进制和 Skill 上，Claude 与 agy 各三个独立数据集均满足业务、清理和易用性门槛。原生输入完整矩阵、EOF 与父退出也已通过；原始失败保留。现允许进入第三批候选制作，第四批最终安装产物验收仍须使用候选本身。

## 本轮交付范围

- 四个标准 MCP 工具：`apps` 紧凑发现、`api` 按需描述、`exec({app,source})`、只读 `result`。没有定制 Host、审批 token、模型请求编号或本地文件依赖。
- macOS WindowServer 窗口表面独立于 AX 语义树；指定窗口截图/坐标点击保留。AX 不可用不会自动使基础库存失效；语义、键盘和可见点输入各有原生条件。
- `focus/typeText/keypress/scroll/setValue`，右键和双击；当前共十个脚本方法。foreground 输入 owner、逐段目标复核、取消与配对释放放在内部。
- WebKit 应用 opt-in 与每个窗口的冷态内容就绪分开；原生分页、筛选及过期引用语义延续。
- 同一稳定 app ID 的多个实例聚合窗口，按 `window_ref` 精确路由。实例加入/退出保留兄弟引用和 app state；所有旧成员替换才 reset。部分库存失败保留可用窗口并标 partial，全失败保留各原始错误。
- Windows 原生实现；Linux X11 实验实现。两者的源码/类型检查与整包构建、实际 GUI 证据分开，Linux 不获得支持承诺。

## 真实 Agent 任务及预设门槛

在真实 Google Chrome 内完成本地库存系统的两项记录审阅：240 条记录、100 条一页、多列表格、关键词筛选、编辑弹窗、数量/复选框/多行中文 emoji 备注；每条只保存一次。随后切换真实 TextEdit，把汇总写入已打开的自有文档并保存。Agent 只经普通 Skill + DTW MCP 操作；服务端保存日志与文档磁盘内容由监督探针独立核验。禁止模型用 DOM、HTTP、shell 或直接文件编辑完成任务。网页是自有业务 fixture；浏览器和编辑器为真实应用，不涉及用户生产数据。

在跑任务前固定：每个 Agent 三个全新独立数据集，同一生产二进制与 Skill；共六次成功。每次最多 8 次 exec、12 次 MCP 调用、40 KiB MCP JSON，无例行成功后的 result 查询；没有未处理的未知效果、重放或替代路线。Skill/工具发现等额外 Agent 调用单独计数；图像单独计量；墙钟记录中位数，不用一次模型/网络延迟做时间保证。准备、监督读回与自有窗口清理不计入模型任务调用数。

复现入口：`tests/acceptance/browser_workbench_probe.py`，支持 `--client native|claude|agy`。输出目录必须全新，保存原日志、二进制 hash、独立最终状态及失败，不修改旧样本。`native` 仅用于路径诊断，不能算作模型验收。Claude 使用更新后的 acpx 0.21.1、官方 Claude ACP adapter 0.95.0 和本机 Claude CLI；模型为 codex/gpt-6.1-terra。agy 使用其普通 MCP 注册及本地 Skill 插件，本次日志证实选择 Gemini 3.8 Flash (High)，未暴露底层模型 revision。两组时间分别记录，不能将不同模型的墙钟差异归因于客户端性能。
