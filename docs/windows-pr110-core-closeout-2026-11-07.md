# PR #110 Windows 核心流程复验

本轮使用 Windows 11 23H2、普通用户桌面、单屏 125% 和已安装的 DSH 0.2.2-rc.1。六组业务任务均通过实际 DSH 的 ACP profile 和完整 Cordis 插件运行。Stop 使用同一候选包的实际 Windows Desktop 会话和「停止生成」按钮。

C08 的产品和 Skill 来源为 e9bd234a6058460a2dd5abbc341dd080981d4d31。完整包 ID、二进制及 ZIP 哈希在[脱敏证据](evidence/windows-pr110-2026-11-07/core-closeout.json)中。此包为本地开发候选。正式发布流程会从版本标签重新构建。

## 动作和自动观察

自动观察单列在 observation 中。对于普通观察错误，脚本结果和动作的派发回执仍然保留，失效图像不会送回。显式读取失败、应用身份异常、取消、超时和清理失败仍按原错误合同报告。权限或读取错误的处理仍受原有窗口归属和输入检查约束。

Chrome 的正确脚本实测出现一次 dispatched 与 observation.failed 同时返回，且 DSH 将调用记为完成。独立 HTTP 日志随后见到预期页面和唯一一次正确表单提交。动作是否在目标生效仍需由后续观察或业务证据确认。

## 同包两种提示

对照要求模型原样调用已给出的 JavaScript，并核对每段执行恰好一次。目标模式只给业务目标、测试资源边界和随包 Skill。Explorer 两轮均以自有目录中的目标文件已选中为初始条件，旁边另有一个独立校验文件。

| --- | --- | --- | --- |
| 修改现有 Notepad 文档、保存、关闭并重开读回 | 6 次工具调用，0 次失败 | 21 次，1 次失败 | 实际 UTF-8/CRLF 字节精确，无末尾换行。原生标题记录独立证明关闭、重开和再关闭，重开后返回了实际文本。 |

所有正式六轮都保持目标范围，业务与收尾通过，且没有派发被标记为 unknown。保留两类控制错误。最早的浏览器入口先有监督脚本导入失败，下一轮的对照又因翻译浮层挡住主窗标题校验而在业务输入前停止。修正脚本后使用新窗口重跑。文档首轮对照的测试字符串转义错误由模型修正，尽管磁盘和窗口转换正确，仍未计入原样对照，随后用新文档严格复跑。

| 归因 | 此轮观察和判断 |
| --- | --- |
| DTW 或平台能力 | Chrome 视觉路线有一次派发前遮挡拒绝。另一次点击已派发，脚本主动发起的 look 遇到可见性变化失败，重新观察后继续。Explorer 的一次自动观察产生 invalid_observation，保留失败字段和已派发回执，随后读回确认了改名。 |

## Windows Desktop Stop

A04 在独立会话加载 C08。监督器就绪后仅让自有夹具移动 12 像素，模型看到新位置、重新截图，随后通过同一脚本发起真实拖拽和候选后缀。监督器收到左键仍按住且至少一次原生移动的样本后，开始点击 Desktop 的「停止生成」。

原生夹具记录 11 次移动、一次释放、零次后缀 Increment。DSH 归档记录用户中止和 execution_interrupted，保留原宿主错误。同会话先用新只读观察恢复，再通过同一个进程实例的 MCP 写入并保存新值恰好一次。核对了进程 ID、出生时间、二进制路径、保存字节、夹具退出码以及键已释放。

点击操作开始后约 226 ms 观察到原生释放。Desktop 上的物理按钮按下样本约晚 71 ms，因此释放证据不单独归因于按钮回调。实际 Desktop 用户取消与原生清理各自有独立证据。A01 在清理监督辅助层后正常完成拖拽和后缀，随后点 Stop 的时候已释放。A02 未派发。A03 在监督器就绪前正常完成。三轮原始失败都保留。

测试结束后正常关闭自有夹具、记事本窗口和候选 Desktop。原 Desktop 插件配置逐字节恢复并正常重启，核对了实际加载的原 MCP 与原会话。

## 发版判断

现有核心范围六组业务和 Windows Desktop Stop 均通过。保留的普通拒绝和易用性问题都有安全读回与完成证据。当前未发现需要阻止下一稳定版的核心问题。#109 原始 a01 的消费及收尾仍然未知，关闭 issue 依据后续实机修复证据。混合 DPI、跨屏和未来扩展不在本轮核心验收范围内。

本地 624 项库测试、4 项 CLI 测试及完整包的 CLI/MCP 启动和 EOF 检查通过。候选源提交的 [CI](https://github.com/caelis-labs/desktop-world/actions/runs/42339406902) 五项通过。前一候选的更广原生、视觉与隐藏前台证据见 [C07 Windows 实机验收](windows-pr110-acceptance-2026-11-07.md)。
