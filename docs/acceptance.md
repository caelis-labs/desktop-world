# Acceptance status

Evidence categories: **source** means code inspection, **contract** means an isolated protocol or fixture check, **live** means a real UI effect with independent readback, and **Agent** means a fresh Gemini session used the installed Skill and sole DTW `exec` for desktop operations. The detailed chronological POC record remains in Git history at `cd20319b6b6e842bc5b4587788e76070e82e4a11:docs/cua-thin-final-poc.md`; evidence artifacts from that run are under `/private/tmp/dtw-cua-*` on the test machine. They do not prove a new formal build until this tree is tested separately.

The prior POC showed these real tasks: a temporary Chrome form, an 800-button browser tree with screenshot click and native menu reload, copied WPS DOCX editing with `textutil` readback, and an Obsidian vault created through a persistent system chooser with independent `.obsidian` readback. A user Chrome Bilibili like was visually observed and undone; remote account server state was not independently checked. A later fresh Gemini run used the CLI-installed Skill's screenshot-region recipe and clicked one AX-backed candidate in 3 `exec` calls, with 0 failed receipts and an independent page readback. See that commit's ledger for timing, retries, error cases, and exact artifact paths.

Run non-destructive protocol checks on a newly built package with:

```sh
python3 tests/acceptance/probe.py /path/to/package/bin/dtw
python3 tests/acceptance/contract_probe.py /path/to/package/bin/dtw
python3 tests/acceptance/native_ops_probe.py /path/to/package/bin/dtw
```

Real GUI harnesses in `tests/acceptance/` launch temporary Chrome, Obsidian, or WPS instances and may take foreground focus. They are manual, not CI tests. The WPS Agent harness requires an explicit test DOCX argument; the Bilibili harness requires an exact user Chrome PID/window ID and authorization for a like followed by undo. Antigravity harnesses install only inside a temporary project and restore their temporary one-tool permission rule if they add it. Do not run them while another person is using the same desktop.
